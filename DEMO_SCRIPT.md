# Presentation Demo Script

1. Open `index.php` and introduce the store purpose.
2. Open the merchandise page and show products loaded from MySQL.
3. Register or log in as a student.
4. Add a product to the cart and place an order.
5. Book an event ticket and show the generated ticket code in **My Account**.
6. Change the test user's role to `club_admin` in phpMyAdmin, then log in again.
7. Open **Admin** and show product/event management.
8. In **Orders & Payments**, mark the ticket payment as `paid`.
9. Use **Ticket Check-in** to validate the ticket code.
10. Open **Reports** to show attendance and sales data.

Use `TESTING_CHECKLIST.md` before presenting to make sure each feature works.
